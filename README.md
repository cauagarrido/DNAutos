# DNAutos Vistorias

Plataforma de consulta veicular da DNAutos Vistorias, criada para ajudar quem está avaliando a compra de um veículo a tomar decisões com mais informação.

## O que a plataforma oferece

- **Tabela FIPE gratuita:** consulte o preço médio de referência por marca, modelo e ano, sem criar uma conta.
- **Consulta por placa:** acesse informações sobre o histórico do veículo e sua situação, conforme os dados disponíveis para aquela placa.
- **Histórico de compras:** acompanhe pagamentos e volte a acessar os relatórios concluídos pela sua conta.
- **Atendimento:** entre em contato para tratar erros ou solicitar análise de estorno.

## Como funciona para o cliente

Na Tabela FIPE, basta escolher o tipo de veículo, a marca, o modelo e o ano para visualizar o valor de referência. Essa consulta é gratuita e não exige login.

Para consultar uma placa, o cliente entra na conta, informa a placa e confirma a compra de R$ 50,00 por veículo. Após a confirmação do pagamento, a consulta fica disponível no histórico de compras. O relatório concluído permanece acessível na conta.

## Informações importantes

As consultas por placa estão em preparação e serão disponibilizadas após a conclusão das integrações necessárias. A cobertura das informações depende dos dados retornados para cada veículo; um dado ausente não comprova a inexistência de ocorrências.

A Tabela FIPE apresenta um preço médio de referência. Ela não substitui uma consulta por placa nem uma avaliação presencial do veículo.
